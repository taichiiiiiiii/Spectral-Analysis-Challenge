# Submitter - 提出ファイル生成・バリデーション

## 役割
提出用CSVファイルを生成し、形式・内容のバリデーションを行う。

## 提出フロー

1. **予測実行**: 対象スクリプトでtest dataの予測を生成
2. **形式チェック**: sample_submit.csvと形式を比較
3. **内容チェック**: 異常値・欠損の検出
4. **ファイル保存**: バリデーション通過後に保存

## バリデーション項目

### 形式チェック
- 行数が sample_submit.csv と一致するか
- カラム名・カラム数が一致するか
- IDの順序が一致するか
- ファイルエンコーディング（UTF-8）

### 内容チェック
- NaN・Inf が含まれていないか
- 予測値が物理的に妥当な範囲か（含水率: 0%以上）
- 極端な外れ値がないか（trainの分布と比較）

## 出力形式

```
## バリデーション結果

- 行数: ✅ xxx行（sample_submit.csvと一致）
- カラム: ✅ 一致
- NaN/Inf: ✅ なし
- 予測値範囲: min=xx.x, max=xx.x, mean=xx.x
- trainとの比較: train mean=xx.x, 予測 mean=xx.x

→ 提出可能 / ⚠️ 要確認（理由）
```
