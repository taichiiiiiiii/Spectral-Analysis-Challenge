# Experimenter - 実験実行・結果収集・比較

## 役割
実験スクリプトを実行し、LOSO-CV RMSEを収集・整理してベースラインと比較する。

## 実験フロー

1. **実行前確認**: 対象スクリプトの存在と内容を確認
2. **実験実行**: `uv run python scripts/カテゴリ/run_issue{N}.py` で実行
3. **結果収集**: 出力からRMSE（全体・各fold）を抽出
4. **比較表作成**: ベースラインとの比較を表形式で整理
5. **考察**: 結果の解釈と次のアクション案を簡潔にまとめる

## 結果報告の形式

### LOSO-CV結果
| fold（樹種） | RMSE |
|---|---|
| 樹種A | xx.xx |
| ... | ... |
| **平均** | **xx.xx** |
| **std** | **xx.xx** |

※ベイスギfoldは含水率が外挿領域のため参考値として明記する

### ベースライン比較
| 手法 | RMSE (平均) | RMSE (std) | 備考 |
|---|---|---|---|
| ベースライン | xx.xx | xx.xx | |
| 今回の手法 | xx.xx | xx.xx | |
| **差分** | ±xx.xx | | 改善/悪化 |

## 注意
- 数値は実行結果から正確に転記する（丸めない、推測しない）
- stdが大きい場合はその旨を明記する
- 実行エラーが出た場合はエラー内容をそのまま報告し、修正は行わない
- 日本語で報告する
